# 运营操作手册（AI 汽车运营官）

这套系统是一名“AI 运营员工”：它每天自动研究市场、规划各账号内容、在小红书公开内容里寻找真正想买车的人、判断意向、分配给最合适的账号、起草私信和回复。**你主要负责审核关键决定和处理例外**，所有步骤都有记录。

## 零、第一次使用（「设置」页）

系统**不内置任何门店、品牌、车型或账号**，一切都用你自己的真实信息：

1. **填写门店信息**：门店名称、经营品牌（多个用逗号分隔）、城市，可选省份、电话、营业时间、地址。
2. **添加在售车型**（建议）：品牌、车型、配置/版本、年款、厂商指导价，可选卖点和客户常用叫法。价格、配置只会引用这里的数据。
3. **添加小红书账号**（「账号」页 → 添加您的小红书账号）：填写昵称、账号类型（销售号要填销售姓名）和该账号的 xiaohongshu-mcp 实例地址。
4. **扫码登录**：账号卡片上点「扫码登录」，**用该账号本人的小红书 App 扫码**；登录成功后状态变为“已登录”。
5. 至少有一个账号**真实检测为已登录**后，才能下达经营目标、运行获客任务；在此之前系统会明确提示缺少哪一步。

填错的门店、车型或账号可以删除（已有线索、私信或内容记录的不能删除，账号可改为「暂停」）。

## 一、每天的工作流程

1. **登录**：输入你的姓名和控制台密码。你的姓名会记录在审核、发送、成交等操作里。
2. **看「总览」**
   - 四个数字：高意向线索、预计管道价值、今日到店预约、需要你处理。
   - 「需要你处理」列表：待审核私信、待人工发送、需要人工接管的对话、待审批内容、未确认预约、账号问题等，点右侧按钮直接去处理。
   - 顶部提示条要看：**“模拟数据模式”** 表示数据是合成的；**“需要扫码登录”** 表示小红书会话掉线，此时不会有新线索（不是“没有客户”）。
3. **下达经营目标**（总览页）：用一句话说清楚，例如“这个月在〈你的城市〉获取〈你的车型〉线索，重点推现车”。系统会拆解成搜索词、发现、评分、分配、私信草稿和内容计划，进度在「系统 → 自动任务」可见。
4. **处理线索（「线索」页）**
   - 每张卡片都直接显示：分数与分层、车型、地区、购买阶段、**客户原话**、出处（笔记标题、时间、**查看原帖**链接）、判断依据、负责账号、下一步。
   - 标签含义：**数据来源**（真实数据 / 导入数据 / 模拟数据）；**身份**（潜在买家 / 车主 / 内容创作者 / 车商销售 / 汽车爱好者）。只有“潜在买家”会成为线索，车主、博主、同行不会被当成客户。
   - 同一个人在多篇笔记下留言会被**合并成一条线索**，只由一个账号负责联系。
5. **审核并发送私信（线索详情页 → 私信）**
   - 系统写好的私信基于客户原话和门店真实数据（价格、现车、优惠均来自 Dealer Brain）。可以修改后点「审核通过」。
   - 发送前检查会列出：负责账号、勿扰、防重复、联系频率、账号健康、事实核查、平台规则（**不能出现电话、微信、链接**）、审批策略、发送能力。
   - 小红书没有开放给第三方的私信发送接口，所以：点「复制私信」→ 用**负责账号**的小红书 App 打开客户主页 → 私信粘贴发送 → 回到系统点「**我已在小红书发送**」。只有负责账号可以联系，其他账号不要重复联系。
6. **登记客户回复（线索详情 → 对话，或「对话」页）**
   - 客户在私信里回复后，把原话粘贴进来。AI 会识别问价、问现车、贷款、置换、预约、留资、拒绝等意图，提取车型、预算、时间等信息，并起草有事实依据的回复。
   - 回复草稿同样需要审核，复制到 App 发送后点「我已在小红书发送」。
   - 对话变复杂（砍价、投诉、多轮 AI 回复）时会标记“需要人工接管”。
7. **预约与成交**
   - 客户说“周六下午去店里看看”会自动生成**待确认预约**。确认时间后点「确认预约」，到店后点「已到店」，没来点「未到店」。
   - 成交点「登记成交」（可填金额），流失点「标记流失」并写原因。
8. **内容（「内容」页）**
   - 日历按账号显示一周内容。每个账号人设不同，同一车型/主题不会在多个账号近期重复。
   - 待处理内容：生成正文 → 事实与合规审核 → 批准。发布需要图片；无法自动发布时，在对应账号 App 发布后，把**笔记链接**登记回来。
   - 「哪些内容真正带来成交」按成交、预约、合格线索排序，不看点赞。
   - 评论回复：只回复我们自己笔记下的评论。
9. **账号（「账号」页）**
   - 每个账号显示人设、主推车型、健康度、负责线索数、回复率、预约与成交、登录状态。
   - 登录状态显示“需要扫码登录”时：点「扫码登录」，**用该账号本人的小红书 App 扫码**。二维码只在弹窗里显示，不会保存。
   - 账号异常可以「暂停」，暂停后不会被分配线索或发布内容。
10. **情报与日报（「情报」页）**：每个搜索词带来多少合格线索（线索密度）、最近搜索任务（失败原因如实显示）、研究简报、运营日报。

## 二、必须遵守的规则

- **用户说“不需要/别再发了”**，系统会立即把他加入**全局勿扰**，所有门店、所有账号都不会再联系。你也可以在线索详情里手动「加入勿扰」。
- **不群发、不重复联系**：一个客户只由一个账号负责；私信有每日上限和间隔；未回复的跟进次数有限制。
- **不在私信里发电话、微信或链接**。需要联系方式时引导客户使用名片/留资卡。
- **价格、库存、优惠只说 Dealer Brain 里的真实数据**，并提示“以到店书面报价为准”。优惠过期或库存变化后要在「系统 → Dealer Brain」更新。
- 车主故事类内容必须取得车主本人授权。

## 三、数据维护（「系统」页）

- **Dealer Brain**：导入/更新门店、车型、库存（默认按快照：文件里没有的库存会置 0）、优惠、销售、知识与账号人设；可直接修改库存状态数量、优惠金额与截止日期；可新增优惠。
- **评分配置**：调整各因素权重与候选/合格/高意向/立即跟进阈值，每次保存生成新版本。
- **导入真实公开内容**：可导入从小红书真实导出的笔记与评论（标记为“导入数据”）。
- **自动任务**：查看每个任务的每一步；因能力不可用而跳过的步骤会写明原因；失败或中断的任务可以「恢复」。
- **能力状态**：每个账号的搜索、发布、私信等能力的最近一次真实检测结果。

## 四、常见问题

| 看到的情况 | 含义 / 怎么做 |
|---|---|
| 顶部“需要扫码登录” | 小红书会话掉线，去「账号」扫码 |
| 私信一直是“已通过·待人工发送” | 正常：私信只能人工在 App 发送，发送后点「我已在小红书发送」 |
| 内容“待人工发布” | 缺图片或无法自动发布：上传图片后重新排队，或人工发布后登记笔记链接 |
| 线索标着“模拟数据” | 测试/演示数据，不是真实客户，生产环境不会出现 |
| 某条评论没有变成线索 | 说话的人是车主、博主、同行或只是夸车，系统有意不把他们当客户；可在线索页筛选“身份”查看判断依据 |
